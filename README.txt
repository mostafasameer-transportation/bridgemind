BRIDGEMIND LIVE WEBSITE
========================

Open index.html in a modern browser or deploy the folder to a static web host.

Included:
1. BridgeMind™ visual identity and logo
2. Miami-Dade DTPW bridge geometry layer
3. Public FHP / FL511 ArcGIS operational feeds for congestion and closures
4. Official FL511 real-time traffic map panel
5. 60-second automatic refresh
6. Bridge selection with nearby operational context
7. Disaster / bridge closure scenario interface
8. BridgeMind copilot prototype
9. Researcher and project information
10. Data provenance and engineering-use disclaimer

Important:
The site reads external public web services. A browser must have internet access.
The disaster simulation values are illustrative UI outputs. They are not forecasts or engineering design calculations.
The 644-bridge and 18-critical research figures are the current BridgeMind research baseline used for the prototype.
For production use, connect the final validated RNI / NBI / inspection dataset and a backend retrieval-augmented AI service.

Update 2026-09-22: switched basemap from OpenStreetMap raster tiles to ArcGIS World Street Map and switched FL511 to its official /Map/EmbeddedMap endpoint to avoid the 403/blank panels shown in the screenshot.
